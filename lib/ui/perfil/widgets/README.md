# Widgets de la feature

Esta carpeta almacena los widgets específicos de esta pantalla o módulo.  
Pueden ser formularios, listas, tarjetas o componentes visuales que no se comparten con otras partes de la app.

Reglas:
- Mantener los widgets pequeños y reutilizables dentro de la misma feature.
- Si un widget empieza a usarse en varias pantallas, debe moverse a `ui/core/widgets/`.
